# Omni Constitution

The foundational governance document for the [Omni](https://omni.dev) ecosystem.

## Documents

- **[Preamble](PREAMBLE.md)** — why this constitution exists
- **[Principles](PRINCIPLES.md)** — the ten non-negotiable commitments
- **[Bill of Rights](RIGHTS.md)** — rights of users, developers, and the community
- **[Amendment Process](AMENDMENTS.md)** — how this constitution evolves

## Purpose

This constitution establishes the values, principles, and rights that govern the Omni ecosystem. It binds the creators, maintainers, and stewards of Omni to commitments that no business decision can override.

## Contributing

Proposed changes to this constitution follow the [amendment process](AMENDMENTS.md). Open a pull request with a detailed rationale to begin.
